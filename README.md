# Tile Calculator

Tile Calculator is an Android application built with Jetpack Compose that helps users easily calculate the number of tiles needed for a given area, estimate costs, and manage calculation history.

## Features

*   **Tile Calculation**: Accurately calculate the number of tiles required based on room dimensions and tile sizes.
*   **Cost Estimation**: Calculate the total cost by entering the price per tile or box.
*   **Calculation History**: Keep track of your past calculations for quick reference.
*   **Detailed Results**: View comprehensive details of your calculations.
*   **Settings**: Customize your experience with various settings (theme, dynamic color, etc.) using DataStore Preferences.
*   **Modern UI**: Built entirely with Jetpack Compose and Material Design 3, including dynamic theming and edge-to-edge support.
*   **Dark/Light Mode**: Full support for both themes.

## Tech Stack

*   **Language**: [Kotlin](https://kotlinlang.org/)
*   **UI Toolkit**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
*   **Architecture**: MVVM (Model-View-ViewModel)
*   **Navigation**: [Jetpack Navigation Compose](https://developer.android.com/jetpack/compose/navigation)
*   **Local Storage**: [DataStore Preferences](https://developer.android.com/topic/libraries/architecture/datastore)
*   **State Management**: `StateFlow` and Compose State
*   **Theming**: Material 3 (M3) with Dynamic Colors

## Requirements

*   Minimum SDK: 24 (Android 7.0)
*   Target SDK: 37
